# Security policy

GitHub Private Apps handles GitHub credentials and serves private repositories
to the Home Assistant Supervisor, so security reports are welcome.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub private vulnerability reporting](https://github.com/Gluxur/ha-github-private-apps/security/advisories/new).

Include what you can: affected version, steps to reproduce, and impact.
You should get a first answer within a week.

## Supported versions

Only the latest release receives fixes.
